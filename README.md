## Zig World Map

World map of Zig programmers, events, and mirrors.

## Developing
Requirements: `zig` ([version](https://github.com/zig-bd/map/blob/main/build.zig.zon#L5))

Start dev server (http://localhost:3000):
```bash
zig build dev
```

Build static site (output in `dist/`):

```bash
zig build zx -- build --static
```
Built with

- Ziex: https://ziex.dev
- Zig: https://ziglang.org
